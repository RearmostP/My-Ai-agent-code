# סוכן קוד מקומי

יישום FastAPI מקומי לעריכת פרויקטים בעזרת מודל OpenAI-compatible. ממשק המשתמש בעברית ו-RTL; קוד, נתיבים ו-diff מוצגים ב-LTR.

## התקנה והפעלה

1. התקינו Python 3.10 ומעלה, והתקינו תלויות: `python -m pip install -r requirements.txt`.
2. הגדירו `OPENROUTER_API_KEY` בקובץ `.env`. ניתן לשנות שם גם את `API_BASE_URL`, `MODEL_NAME`, `SERVER_HOST` ו-`SERVER_PORT`.
3. הפעילו `python main.py` ופתחו `http://127.0.0.1:8000`.
4. הזינו נתיב מלא לקובץ או לתיקיית הפרויקט במחשב שבו רץ השרת.

הגדרות הסוכן נשמרות ב-`agent_rules.json` וניתנות לעריכה מתוך ממשק ההגדרות. אם מוגדר קובץ כללים חיצוני, חייבים להיות מסוגלים לקרוא אותו לפני ביצוע שינויים; נתיב חסר או קובץ לא קריא יעצור את הבקשה. קובצי מפתחות וסודות (`.env`, `key.env`, `key1.env`) ו-`.git` מוגנים תמיד ואינם נשלחים למודל, גם אם הוסרו מרשימת ההתעלמות.

## זרימת Git

במאגר Git, מצב ענף AI עובר לענף שהוגדר, מחיל שינויים, מבצע commit ודוחף ל-`origin` אם קיים. מצב ענף ראשי עובר לענף שהוגדר, עורך קבצים וממתין לאישור מפורש לפני commit/push. ביטול האישור משאיר את הקבצים מקומית. אם אין Git, העריכה מתבצעת בלי פקודות Git. החלפת ענף נעצרת כאשר קיימים שינויים מקומיים לא שמורים.

## רשת ואבטחה

ברירת המחדל ב-`.env` היא `0.0.0.0` כדי לאפשר גישה ברשת. לשרת אין אימות משתמשים; כל מי שיכול להגיע אליו יכול לבקש קריאה/עריכה של קובצי פרויקט ולהפעיל Git. השתמשו רק ברשת מהימנה, או הגדירו `SERVER_HOST=127.0.0.1` לגישה מקומית בלבד. אל תחשפו את השרת לאינטרנט. מפתחות נשמרים ב-`.env` שאינו מנוהל ב-Git.
